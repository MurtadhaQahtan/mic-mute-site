Un raccourci pour couper le micro dans toutes les applications Windows

Mic Mute Hotkey est une petite application de la zone de notification pour Windows 10/11. Appuyez sur Win+Alt+A (ou le raccourci de votre choix) et le micro de Windows lui-même est coupé : visioconférences, chats vocaux, navigateurs, enregistreurs et jeux reçoivent du silence. Appuyez de nouveau pour le réactiver. Un indicateur Coupé / Actif reste toujours visible.

Fonctionnement

  1. Windows possède un interrupteur de coupure pour chaque micro (Paramètres › Système › Son › Entrée), mais aucun raccourci clavier. Mic Mute Hotkey actionne cet interrupteur via l’API Core Audio de Windows.
  2. Comme le micro est coupé au niveau du système, toutes les applications reçoivent du silence : inutile de chercher le bouton dans chacune.
  3. L’application tourne dans la zone de notification. L’icône et l’indicateur à l’écran montrent toujours l’état actuel.

Fonctionnalités

  • Raccourci global pour couper et réactiver ; par défaut Win+Alt+A. Si un autre programme l’utilise déjà sur votre PC, l’application choisit une alternative libre.
  • Appuyer pour parler : coupé tant que vous ne maintenez pas une touche (Ctrl droite, F13, bouton latéral de souris, Ctrl+Espace…).
  • Appuyer pour couper : actif tant que vous ne maintenez pas une touche.
  • Indicateur à l’écran toujours au premier plan ; les clics le traversent, il se déplace et sa taille, son opacité et sa position se règlent ; affichage possible uniquement micro coupé.
  • Icône de notification : rouge coupé, vert actif ; clic pour basculer.
  • Suit le micro par défaut quand vous branchez un casque ou changez de périphérique ; option pour couper tous les micros.
  • Sons facultatifs, démarrage avec Windows, démarrage micro coupé, réactivation à la fermeture, vumètre d’entrée.
  • Interface en 15 langues avec détection automatique ; mise en page de droite à gauche pour l’arabe.
  • Confidentiel : hors ligne, sans compte, sans télémétrie ni publicité ; aucun son n’est enregistré.

Limites

  • Windows uniquement (Windows 10 1809 ou ultérieur, Windows 11).
  • Les applications affichent toujours leur propre bouton micro comme actif : elles reçoivent du silence de Windows, mais leur icône ne change pas.
  • Les touches d’appuyer pour parler ne sont pas détectées lorsqu’un programme exécuté en administrateur est au premier plan (règle de sécurité de Windows). Le raccourci de bascule fonctionne.
  • Les jeux en plein écran exclusif peuvent masquer l’indicateur ; le mode fenêtré sans bordure fonctionne.
  • Les boutons de coupure agissant dans le matériel d’un casque ne sont pas visibles par l’application.

Questions fréquentes

Comment couper le micro avec un raccourci clavier sous Windows 11 ?

Windows 10 et 11 n’ont aucun raccourci qui coupe le micro pour tout le système. Mic Mute Hotkey en ajoute un : appuyez sur Win+Alt+A (ou la combinaison de votre choix) et le micro de Windows est coupé dans toutes les applications. Appuyez de nouveau pour le réactiver.

Existe-t-il un appuyer pour parler qui fonctionne dans toutes les applications Windows ?

Oui. Dans Mic Mute Hotkey, choisissez le mode « Appuyer pour parler » et une touche comme Ctrl droite ou F13. Le micro reste coupé pour toutes les applications et n’est actif que lorsque vous maintenez la touche.

Est-ce que cela fonctionne dans Zoom, Microsoft Teams, Discord, Google Meet et les jeux ?

Oui, car le micro est coupé dans Windows lui-même : tout programme qui enregistre depuis ce micro reçoit du silence. Les boutons de ces applications ne changent pas.

Comment savoir si mon micro est coupé ?

Mic Mute Hotkey affiche un indicateur toujours visible (« Coupé » en rouge, « Actif » en vert) et l’icône de notification change de couleur.

Mic Mute Hotkey enregistre-t-il ou envoie-t-il ma voix ?

Non. Il n’a ni accès à internet, ni télémétrie, ni compte. Il modifie seulement le réglage de coupure de Windows.
