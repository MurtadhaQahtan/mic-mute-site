Um atalho para silenciar o microfone em todos os aplicativos do Windows

Mic Mute Hotkey é um pequeno aplicativo de bandeja para Windows 10/11. Pressione Win+Alt+A (ou o atalho que preferir) e o próprio microfone do Windows fica no mudo: videochamadas, chats de voz, navegadores, gravadores e jogos recebem silêncio. Pressione de novo para ativar. Um indicador Mudo / Ativo fica sempre visível.

Como funciona

  1. O Windows tem uma chave de mudo para cada microfone (Configurações › Sistema › Som › Entrada), mas nenhum atalho de teclado. O Mic Mute Hotkey aciona essa chave pela API Core Audio do Windows.
  2. Como o microfone é silenciado no nível do sistema, todos os aplicativos recebem silêncio — não é preciso procurar o botão de mudo em cada um.
  3. O aplicativo fica na bandeja do sistema. O ícone e o indicador na tela sempre mostram o estado atual.

Recursos

  • Atalho global para silenciar e ativar; padrão Win+Alt+A. Se outro programa já usa esse atalho no seu PC, o app escolhe uma alternativa livre.
  • Apertar para falar: no mudo até você segurar uma tecla (Ctrl direito, F13, botão lateral do mouse, Ctrl+Espaço…).
  • Apertar para silenciar: ativo até você segurar uma tecla.
  • Indicador na tela sempre visível; os cliques passam através dele, pode ser arrastado e ter tamanho, opacidade e posição ajustados; opcionalmente só no mudo.
  • Ícone na bandeja: vermelho no mudo, verde ativo; clique para alternar.
  • Segue o microfone padrão ao conectar um headset ou trocar de dispositivo; opção de silenciar todos os microfones.
  • Sons opcionais, iniciar com o Windows, iniciar no mudo, ativar ao sair, medidor de nível de entrada.
  • Interface em 15 idiomas com detecção automática; layout da direita para a esquerda para o árabe.
  • Privado: offline, sem conta, sem telemetria nem anúncios; nunca grava áudio.

Limitações

  • Somente Windows (Windows 10 1809 ou posterior, Windows 11).
  • Os aplicativos continuam mostrando o próprio botão de microfone como ligado: eles recebem silêncio do Windows, mas o ícone deles não muda.
  • As teclas de apertar para falar não são detectadas enquanto um programa executado como administrador está em primeiro plano (regra de segurança do Windows). O atalho de alternar funciona.
  • Jogos em tela cheia exclusiva podem cobrir o indicador; em janela sem bordas funciona.
  • Botões de mudo que atuam no hardware do headset não são vistos pelo aplicativo.

Perguntas frequentes

Como silenciar o microfone com um atalho de teclado no Windows 11?

O Windows 10 e 11 não têm um atalho que silencie o microfone no sistema todo. O Mic Mute Hotkey adiciona um: pressione Win+Alt+A (ou a combinação que quiser) e o microfone do Windows fica no mudo em todos os aplicativos. Pressione de novo para ativar.

Existe apertar para falar que funcione em todos os aplicativos do Windows?

Sim. No Mic Mute Hotkey, escolha o modo “Apertar para falar” e uma tecla como Ctrl direito ou F13. O microfone fica no mudo para todos os aplicativos e só fica ativo enquanto você segura a tecla.

Funciona no Zoom, Microsoft Teams, Discord, Google Meet e em jogos?

Sim, porque silencia o microfone no próprio Windows: todo programa que grava desse microfone recebe silêncio. Os botões de mudo desses aplicativos não mudam.

Como saber se o meu microfone está no mudo?

O Mic Mute Hotkey mostra um indicador sempre visível (“Mudo” em vermelho, “Ativo” em verde) e o ícone da bandeja muda de cor.

O Mic Mute Hotkey grava ou envia a minha voz?

Não. Ele não tem acesso à internet, telemetria nem conta. Apenas altera a configuração de mudo do Windows.
