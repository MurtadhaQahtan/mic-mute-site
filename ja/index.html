ショートカット 1 つで、Windows のすべてのアプリのマイクをミュート

Mic Mute Hotkey は Windows 10/11 用の小さなトレイ アプリです。Win+Alt+A (または好きなショートカット) を押すと Windows のマイクそのものがミュートされ、ビデオ会議、ボイスチャット、ブラウザー、録音ソフト、ゲームのすべてに無音が送られます。もう一度押すと解除。ミュート中 / オン のインジケーターが常に最前面に表示されます。

Microsoft Store から入手

Microsoft Store で 2.99 米ドルの買い切り (各国の価格は Microsoft が設定)。Windows 10 (1809 以降) と Windows 11、x64 と ARM64。

しくみ

  1. Windows には各マイクにミュートのスイッチ (設定 › システム › サウンド › 入力) がありますが、キーボード ショートカットはありません。Mic Mute Hotkey は Windows Core Audio API でこのスイッチを切り替えます。
  2. システム レベルでマイクをミュートするので、すべてのアプリに無音が届きます。アプリごとにミュート ボタンを探す必要はありません。
  3. アプリは通知領域 (タスク トレイ) で動作し、アイコンと画面上のインジケーターが常に現在の状態を示します。

機能

  • グローバル ショートカットでミュート / 解除。既定は Win+Alt+A。PC で別のプログラムが使用中の場合は、空いている代替キーを自動で選びます。
  • プッシュ トゥ トーク: キー (右 Ctrl、F13、マウスのサイドボタン、Ctrl+Space など) を押している間だけ話せます。
  • プッシュ トゥ ミュート: キーを押している間だけミュート。
  • 画面上のインジケーター: 常に最前面、クリックは透過、ドラッグで移動、サイズ・不透明度・位置を調整可能。ミュート中のみの表示も可能。
  • トレイ アイコン: ミュート中は赤、オンは緑。クリックで切り替え。
  • 既定のマイクに追従: ヘッドセットの接続やデバイス変更に対応。すべてのマイクをミュートするオプションもあります。
  • 効果音 (オプション)、Windows 起動時に開始、起動時にミュート、終了時に解除、入力レベル メーター。
  • 15 言語の UI (自動判別)。アラビア語は右から左のレイアウト。
  • プライバシー: オフライン、アカウント・テレメトリ・広告なし。音声は一切録音しません。

制限事項

  • Windows 専用 (Windows 10 1809 以降、Windows 11)。
  • 各アプリ内のマイク ボタンの表示はオンのままです (Windows から無音が届きますが、アプリのアイコンは変わりません)。
  • 管理者として実行中のプログラムが前面にある間は、プッシュ トゥ トークのキーを検出できません (Windows のセキュリティ仕様)。切り替えショートカットは動作します。
  • 排他的フルスクリーンのゲームではインジケーターが隠れる場合があります。ボーダーレス ウィンドウでは表示されます。
  • ヘッドセットのハードウェア内で動作するミュート ボタンはアプリから検出できません。

よくある質問

Windows 11 でショートカット キーを使ってマイクをミュートするには？

Windows 10/11 には、システム全体のマイクをミュートするショートカットがありません。Mic Mute Hotkey を使うと、Win+Alt+A (または好きな組み合わせ) ですべてのアプリのマイクをミュートでき、もう一度押すと解除されます。

Windows のすべてのアプリで使えるプッシュ トゥ トークはありますか？

はい。Mic Mute Hotkey で長押しモードを「プッシュ トゥ トーク」にし、右 Ctrl や F13 などのキーを選びます。マイクはすべてのアプリでミュートされ、キーを押している間だけオンになります。

Zoom、Microsoft Teams、Discord、Google Meet、ゲームでも使えますか？

はい。Windows 側でマイクをミュートするため、そのマイクから録音するすべてのプログラムに無音が届きます。各アプリのミュート ボタンの表示は変わりません。

マイクがミュートされているかどうかを確認するには？

常に最前面に表示されるインジケーター (赤「ミュート中」/ 緑「オン」) と、色が変わるトレイ アイコンで確認できます。

Mic Mute Hotkey は声を録音したり送信したりしますか？

いいえ。インターネット接続、テレメトリ、アカウントはありません。Windows のミュート設定を切り替えるだけです。
