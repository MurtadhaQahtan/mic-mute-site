One shortcut to mute your microphone — in every app on Windows

Mic Mute Hotkey is a small Windows 10/11 tray app. Press Win+Alt+A (or any shortcut you choose) and the Windows microphone itself is muted, so video calls, voice chat, browsers, recorders and games all get silence. Press it again to unmute. A red Muted / green Live indicator stays on top of your screen.

How it works

  1. Windows has a mute switch for each microphone (Settings › System › Sound › Input), but no keyboard shortcut for it. Mic Mute Hotkey flips that switch through the Windows Core Audio API.
  2. Because the microphone is muted at the system level, every app receives silence — you do not need to find the mute button inside each app.
  3. The app runs in the notification area (system tray). The tray icon and the on-screen indicator always show the current state.

Features

  • Global toggle shortcut – any key combination; default Win+Alt+A. If another program already uses it on your PC, the app picks a free alternative and shows it.
  • Push-to-talk – stay muted and hold a key (e.g. Right Ctrl, F13, a mouse side button or Ctrl+Space) to speak.
  • Push-to-mute – stay live and hold a key to mute, for coughing or talking to someone in the room.
  • On-screen indicator – always on top, click-through (never blocks your clicks), draggable, with adjustable size, opacity and position; optionally shown only while muted.
  • Tray icon – red when muted, green when live; left-click to toggle, right-click for settings.
  • Follows the default microphone – plug in a headset or change the default device and the new microphone gets the same state; a microphone the app muted earlier is unmuted again. Option to mute all microphones at once.
  • Stays in sync – if the microphone is muted or unmuted in Windows settings, the app picks up the change.
  • Optional short mute/unmute sounds, start with Windows, start muted, unmute on exit, input level meter in the settings window.
  • Interface in 15 languages (English, Spanish, Portuguese (Brazil), French, German, Italian, Russian, Turkish, Polish, Indonesian, Arabic, Hindi, Japanese, Korean, Chinese Simplified), chosen automatically from Windows; right-to-left layout for Arabic.
  • Private – works offline, no account, no telemetry, no ads; audio is never recorded.

Limitations

  • Windows only (Windows 10 version 1809 or later, Windows 11). No macOS, Linux or mobile version.
  • Apps still show their own mute button as “on”: they receive silence from Windows, but their in-app mute icon does not change.
  • Push-to-talk keys are not detected while a program running as administrator is in the foreground (a Windows security rule). The toggle shortcut still works there.
  • Games in exclusive full-screen mode can draw over the indicator; borderless/windowed full-screen works.
  • Mute buttons that work inside a headset’s hardware (not through Windows) are not seen by the app.
  • While the optional level meter is visible, Windows shows its “microphone in use” icon, because the meter has to listen to the microphone. Nothing is recorded.

Frequently asked questions

How do I mute my microphone with a hotkey on Windows 11?

Windows 11 and Windows 10 have no built-in keyboard shortcut that mutes the microphone for the whole system (Win+Alt+K only works inside apps that support it). Mic Mute Hotkey adds one: press Win+Alt+A, or any combination you choose, and the Windows microphone is muted in every app. Press it again to unmute.

Is there a push-to-talk key that works in all apps on Windows?

Yes. In Mic Mute Hotkey, set Hold-key mode to “Push to talk” and choose a key such as Right Ctrl or F13. The microphone stays muted for all apps and is live only while you hold the key. There is also the opposite mode, push-to-mute.

What can I use instead of PowerToys Video Conference Mute?

Video Conference Mute was removed from Microsoft PowerToys in version 0.88. Mic Mute Hotkey covers the microphone part: a global mute shortcut, an on-screen muted indicator and a tray icon, plus push-to-talk. It does not control the camera.

Does it work in Zoom, Microsoft Teams, Discord, Google Meet and games?

Yes, because it mutes the microphone in Windows itself rather than inside one app: every program that records from that microphone receives silence. The apps’ own mute buttons are not changed, so they may still show the microphone as on.

How can I see whether my microphone is muted?

Mic Mute Hotkey shows an always-on-top indicator (“Muted” in red, “Live” in green) that you can place anywhere on the screen, and its tray icon changes color. You can also hide the indicator while the microphone is live.

What happens when I plug in a headset or change the default microphone?

The app follows the default microphone: the new device gets the current mute state, and a microphone that the app had muted is unmuted again, so no device is left muted by accident. You can also choose to mute all microphones at once.

Does Mic Mute Hotkey record or upload my voice?

No. It has no internet access, no telemetry and no account. It only switches the Windows mute setting. The optional level meter reads the current loudness while the settings window is open; the audio is not stored.

Does it work on Windows 10 and on ARM PCs?

Yes: Windows 10 version 1809 or later and Windows 11, on x64 and ARM64 PCs.
